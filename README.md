# ARC Website-Demo

Statische Demo des abgestimmten ARC-Entwurfs mit allen Unterseiten. Die bestehende Jimdo-Website wird nicht verändert.

Veröffentlichung über GitHub Pages unter dem Projektpfad `/arc-website-demo/`. Es werden ausschließlich die freigegebenen Demo-Dateien veröffentlicht.

Das Kontaktformular bereitet nur eine E-Mail vor. Kunden- und Rechnungsportal bleiben externe Links. Die Demo ist mit noindex/nofollow gekennzeichnet.
